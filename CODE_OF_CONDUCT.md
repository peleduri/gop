# Code of conduct

gop follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). It applies in the repository, issues, pull requests, discussions and any other project space, and to everyone taking part.

## Reporting

Report unacceptable behavior privately to the gop maintainers (listed in [MAINTAINERS.md](MAINTAINERS.md)):

- through GitHub private vulnerability reporting on this repository (Security tab, [Report a vulnerability](https://github.com/peleduri/gop/security/advisories/new)), marked as a conduct report; or
- through the maintainers' conduct contact: `[maintainers' conduct contact: to be added when the project has a shared address]`. Until then, use private reporting above.

Reports are handled confidentially by the maintainers, as described in [GOVERNANCE.md](GOVERNANCE.md#code-of-conduct). A maintainer who is involved in a report takes no part in handling it. If gop becomes a CNCF project, reports may also go to the [CNCF Code of Conduct Committee](https://www.cncf.io/conduct/procedures/) at conduct@cncf.io.
